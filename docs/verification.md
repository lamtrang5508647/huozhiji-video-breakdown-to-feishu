## 本轮未验证

- 新通用配置对真实飞书的上传、权限、文档保存回读和用户界面播放。
- 抖音、视频号等平台的原片下载；仓库未内置这些下载器。
- 真实 ASR 模型推理和逐句人工听校；本轮 ASR 检查为本地模型/输出边界单测。
- 真实视频的语义理解、标色判断质量、事实主张、投放效果与 AI 视频生成。
- macOS/Linux 的完整运行和 macOS 浏览器启动。

合成样例明示无真实口播、无人类审片、无远端访问。技术检查 PASS 不转换为
“语义正确”“人工校对完成”或“飞书交付成功”。详细机器回执保存在本机忽略目录，
不把带个人路径的运行日志、业务状态或视频打包上传。

## 兼容性说明

通用版将产品、平台、身份、表 ID 和列名配置化，保留显式选择的旧 27 字段链。
上传计划新增来源回执与可重建输入绑定，旧计划必须由新 builder 重建。
原项目的状态和历史任务不属于仓库分发物；部署升级时应独立验证旧项目兼容性。

通过审核状态误匹配、B站多 P、跨视频同名段 ID、自定义状态路径、
导出媒体被替换等反例，固定原来容易被较小执行模型遗漏的程序检查。
这些规则标准化交付和可追溯性，不保证不同模型的判断能力相等。
