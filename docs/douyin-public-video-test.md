## 修复的问题

1. 页面能播放视频、目标详情接口正常，但常驻“评论前登录”“验证码登录”“登录后看高清”文案
   触发了通用验证码规则，误报 `ACCESS_BLOCKED`。现在仅在精确目标详情、正常状态和绑定可用媒体
   同时成立时排除四种已核实的普通 UI 提示；剩余验证/访问限制继续检查。
2. 目标详情中的候选流缺少规范 `format`，在统一 validator 前触发 `INVALID_PLUGIN_RESULT`。
   现在先统一规范候选，再交给媒体选择和 availableStreams，保留 validator。
3. 等待详情后重新检查当前页面 URL，拒绝进入登录页或另一个目标；正文或验证码组件状态读取失败
   保留 `ACCESS_STATE_UNVERIFIED`，不得把检查失败当作没有门槛。
