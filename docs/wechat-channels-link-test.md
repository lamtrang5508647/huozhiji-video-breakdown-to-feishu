## 正常登录后的真实提取

用户明确允许仅将这一条分享链接提交腾讯元宝，并通过其正常微信扫码入口登录。
在本次独立浏览器会话中，同源解析返回 HTTP 200、明确业务码 0 和真实播放链接；
同一上下文的播放详情请求返回 HTTP 201、`errCode=0`、`data.errMsg.type=0`。
平台文案、作者与此前分享预览一致，详情中实际出现 `videoUrl`、H.264 与 H.265 视频地址。

播放 `eid`、实际详情请求 `exportId` 和详情响应 `sceneInfo.dynamicExportId` 三者精确相等；
详情请求的 `baseReq.generalToken` 与播放 token 精确相等。
解析阶段 `wx_export_id` 与这些标识不同，未把它或分享短链 token 当作原始数字对象 ID。
身份类型明确为 `platform_export_id`，`identity_stability_verified=false`；
本地安全键是可逆编码，不是伪造的平台 ID。
