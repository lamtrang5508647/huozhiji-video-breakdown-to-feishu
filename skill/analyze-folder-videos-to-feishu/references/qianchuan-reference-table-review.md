# 带货参考视频回填与标签

适用于用户提供成片或带货参考链接，要求把原稿、前三秒分析和素材标签填入现有表格的场景。先确认成片身份与可用原片，读取目标表字段和单选项，按真实字段映射。整片拆解的交付范围沿用任务约定。

## 脚本提取

- 从头到尾核对原声及画面字幕，区分原口播、字幕主导的文案和包装或促销等画面素材。语音识别和 OCR 都用于定位和对照。优先核对商品名、数字、单位、否定词、角色、首尾句和错位字幕。
- 将校对后的完整来源文本按原片顺序写入脚本字段，保留原来的表达和必要分段。该格只放脚本正文。识别稿状态、时间点、画面描述、效果判断和复用建议分别放在相应字段或审阅记录。
- 字幕主导素材用完整的创作者字幕文案。若原声与字幕不同，按所需来源分别保存，不把品牌包装、效果贴片或音乐识别误报拼进口播。重复展示同一行字幕只抄一次，原声确实重复的台词保留。
- 来源暂不完整时保留具体待核片段及时间，已核部分可作为单独证据。完整字段只填经核对的完整文本。机器草稿保存在本地证据，复核范围如实记录。

## 前三秒钩子

在同一个分析格写三项，能定位到来源时间。

1. **脚本**写实际 0–3 秒原声、主字幕或两者的差异。话没说完时写实际开头，另在承接里说明下一句。纯画面钩子描述可见动作。
2. **画面**写 0–3 秒对应的人、商品、动作、构图和切点，指出画面如何补充、放大、对照或解释脚本。
3. **留人逻辑**写它让什么人自我识别、抛出什么疑问或结果落差、哪一拍给了继续看的理由，以及下一句或下一镜怎样兑现。描述创意意图和素材内依据，实际留存要用对应投放数据核实。

例如，某厨房用品参考先说「切完蒜最烦什么」，画面前两秒给手上残留蒜末的近景，第三秒手移向台上的器具。问题和实拍让常做饭的人识别清洁麻烦，器具提前入画让观众等操作结果。此例只说明写法。

## 商品赛道、开头需求和跨类目标签

| 字段 | 判断依据 |
| --- | --- |
| 视频赛道 | 片中实际推广的商品类别，优先用包装、商品名、实际展示和清楚的上下文。多商品时用主推广对象或按表允许的粒度记录。处理和复核进度写入状态字段。 |
| 开头切入需求 | 以开头实际说出、写出或演示的痛点、目标或使用场景为主。首句只抛悬念时用紧接的承接确认。优先能区分素材的具体标签，片中后段新增的卖点独立记录。 |
| 素材开投类型 | 记录开场用什么方式表达，比如痛点前置、锁定人群、直切产品、价格机制。具体需求另看上列。 |
| 跨类目对标 | 读取本次目标商品的实际类目、核心需求、用户条件及价格范围，依据当前表的选项选择。单选填证据最充分的主关系，多选可保留有独立依据的多个关系。 |

对常见跨类目选项的判定：

- **原生改编**：原片商品与目标商品同类，且核心需求与使用场景能对应。
- **相同需求**：类目或使用方式不同，原片仍直接回应目标用户的核心需求。相关概念或身体部位不自动等于相同需求。
- **相同人群**：有独立证据表明素材面向已满足目标人群条件的受众。年龄、性别和一般生活方式本身不足以建立重合。
- **相近价格**：有同范围、同单位、可核对的单件价或套餐价，符合本次给出的价格边界或比较区间。片中活动和当前价格按各自时间记录。
- **跨类目尝试**：保留能迁移的开头、证明或演示结构。需求、人群或价格关系的证据另行核对。

相似度同样充分时，按本次业务目标选择最能指导复用的标签，并保存依据。用户授权补选项时，先核对现有名称，复用已有准确标签，只补批次里确有证据的新需求或新商品类目，读回选项后写记录。脚本、钩子和标签都按来源身份逐条回读。业务目标、价位、客户名称、原片及运行证据留在本项目配置。
