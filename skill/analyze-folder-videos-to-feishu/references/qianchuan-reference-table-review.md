# 带货参考视频回填与标签

适用于用户提供成片或带货参考链接，要求把原稿、前三秒分析和素材标签填入现有表格的场景。先确认成片身份与可用原片，读取目标表字段和单选项，按真实字段映射。整片拆解的交付范围沿用任务约定。

## 脚本提取

- 从头到尾核对原声及画面字幕，区分原口播、字幕主导的文案和包装或促销等画面素材。语音识别和 OCR 都用于定位和对照。优先核对商品名、数字、单位、否定词、角色、首尾句和错位字幕。
- 将校对后的完整来源文本按原片顺序写入脚本字段，保留原来的表达和必要分段。该格只放脚本正文。识别稿状态、时间点、画面描述、效果判断和复用建议分别放在相应字段或审阅记录。
- 字幕主导素材用完整的创作者字幕文案。若原声与字幕不同，按所需来源分别保存，不把品牌包装、效果贴片或音乐识别误报拼进口播。重复展示同一行字幕只抄一次，原声确实重复的台词保留。
- 来源暂不完整时保留具体待核片段及时间，已核部分可作为单独证据。完整字段只填经核对的完整文本。机器草稿保存在本地证据，复核范围如实记录。

## 前三秒钩子

在同一个分析格写三项，能定位到来源时间。

1. **脚本**写实际 0–3 秒原声、主字幕或两者的差异。话没说完时写实际开头，另在承接里说明下一句。纯画面钩子描述可见动作。
2. **画面**写 0–3 秒对应的人、商品、动作、构图和切点，指出画面如何补充、放大、对照或解释脚本。
3. **留人逻辑**写它让什么人自我识别、抛出什么疑问或结果落差、哪一拍给了继续看的理由，以及下一句或下一镜怎样兑现。描述创意意图和素材内依据，实际留存要用对应投放数据核实。

例如，某厨房用品参考先说「切完蒜最烦什么」，画面前两秒给手上残留蒜末的近景，第三秒手移向台上的器具。问题和实拍让常做饭的人识别清洁麻烦，器具提前入画让观众等操作结果。此例只说明写法。

## 商品赛道、开头需求和跨类目标签

| 字段 | 判断依据 |
| --- | --- |
| 视频赛道 | 片中实际推广的商品类别，优先用包装、商品名、实际展示和清楚的上下文。多商品时用主推广对象或按表允许的粒度记录。处理和复核进度写入状态字段。 |
| 开头切入需求 | 以开头实际说出、写出或演示的痛点、目标或使用场景为主。首句只抛悬念时用紧接的承接确认。优先能区分素材的具体标签，片中后段新增的卖点独立记录。 |
| 素材开头类型 | 记录开场用什么方式表达，比如痛点前置、锁定人群、直切产品、价格机制。具体需求另看上列。 |
| 跨类目对标 | 读取本次目标商品的实际类目、核心需求、用户条件及价格范围，依据当前表的选项选择。单选填证据最充分的主关系，多选可保留有独立依据的多个关系。 |

对常见跨类目选项的判定：

- **原生改编**：原片商品与目标商品同类，且核心需求与使用场景能对应。
- **相同需求**：类目或使用方式不同，原片仍直接回应目标用户的核心需求。相关概念或身体部位不自动等于相同需求。
- **相同人群**：有独立证据表明素材面向已满足目标人群条件的受众。年龄、性别和一般生活方式本身不足以建立重合。
- **相近价格**：有同范围、同单位、可核对的单件价或套餐价，符合本次给出的价格边界或比较区间。片中活动和当前价格按各自时间记录。
- **跨类目尝试**：保留能迁移的开头、证明或演示结构。需求、人群或价格关系的证据另行核对。

相似度同样充分时，按本次业务目标选择最能指导复用的标签，并保存依据。用户授权补选项时，先核对现有名称，复用已有准确标签，只补批次里确有证据的新需求或新商品类目，读回选项后写记录。脚本、钩子和标签都按来源身份逐条回读。业务目标、价位、客户名称、原片及运行证据留在本项目配置。

## 素材目的、涉及品牌和人工等级

| 字段 | 回填依据 |
| --- | --- |
| 素材目的 | 带货素材的脚本、主字幕或片尾明确把观众引到直播间看品、领券或下单时，填写 `直播引流`。其余商品带货素材填写 `短视频带货`。出现「点击下方」「点购物车」「直接下单」等原句时记录为直接购买引导。生活叙述中说自己待会开播、普通优惠提示或单纯展示价格，不能证明在引导进直播间。 |
| 涉及品牌 | 从脚本找本条实际介绍或推荐的商品牌子，用清楚的字幕、包装或来源标题校准拼写。脚本主要靠画面传达时，以可辨识的商品标识和明确来源信息为依据。单选填主推广品牌，多品牌按表格允许的粒度填写。证据不足时保留空值。 |
| 素材等级 | 由用户评定。新增记录保留空值，更新结果时从写入字段映射省略该列，现有评级由用户维护。 |

核对是否真的出现下单或进直播间的指令，再记录行动引导原文。表格目的分类与实际是否出现指令分别记录。

## 单盒参考价

用户要求价格参考时，先按原片商品名、包装和可核对的来源确定商品，再读取目标表实际字段。`单盒参考价`表示一个销售包装的近似价格；瓶、罐、桶按单瓶、单罐、单桶。它不是品牌客单价，也不等于视频里的整单成交额。

- 查询对应商品的公开在售页或有日期的报价，保存商品身份、来源链接、查询日期、原始标价、促销条件和包装数量。不同代际、口味或容量可能价差很大，不能只凭品牌相同套用价格。视频里的报价须标明是原片当时的说法，不当作当前售价。
- 套装或拍赠价只有在总价和实际到手数量都明确时，才折算单盒。券门槛、品牌价格带、佣金或销售额除销量不能充当单盒价。优惠条件无法满足时，不把折后价说成普通单盒售价。
- 文本字段只填简短近似金额，如 `约90元`、`约90–110元`；数值字段按该字段的单位填数字。**单元格不注明规格，也不拼入来源、优惠说明或核对状态**；这些放在独立审阅证据中。优先保留有依据的范围，避免用过度精确的数值暗示实时成交价。
- 品牌不明、标题与脚本对应不同商品、包装数量无法核对或没有可用单盒报价时，暂留空并记录原因。回写后核对目标记录及价格值；表格回读只证明写入成功，不证明报价仍可下单。

## 内容身份、素材开头类型、素材生态和内容形式

| 字段 | 判断范围 | 判断依据 |
| --- | --- | --- |
| 内容身份 | 全片由谁的立场提出建议 | `用户视角`依据亲身使用、日常记录或个人经历；`专业视角`以方法、原理或专业讲解组织内容，指叙事立场，资质另行核实；`商家视角`由商家、官方账号或销售方代表商品对观众讲解。个人职衔、引用检测和出现购物引导本身不足以改变视角。 |
| 素材开头类型 | 前三秒的主钩子，必要时核对紧接的一句 | `锁定人群`以身份或目标让受众认出自己；`痛点前置`先说出或演出困扰；`直切产品`开场直接展示、使用或介绍商品；`价格机制`先给价、优惠或赠品规则；`同品对比`先比同类商品、版本或配置。开头的需求与表达方式分别填。只交代讲述者身份和当天行程时，按已配置的场景型标签填写。无准确选项时在复核依据里记下原片的开头类型。 |
| 素材生态 | 主要画面、商品呈现及语言载体 | 真人拿取、操作、试吃或展示商品时，按有无实际讲解选对应的真人商品展示。商品、动画或图卡为主要载体且真人只偶尔插入时，按有无讲解选对应的商品展示。旁白也算语音，纯配乐或歌词不算商品讲解。对镜持续讲述才归口播，按实际讲述者人数填写；表演推动时区分单人情景剧和情景演绎；静态图文快速轮播时用图文快闪。结合音轨、字幕、口型或可靠转写核对，按已核实的表现填写并保留复核范围。 |
| 内容形式 | 全片主要组织方式和购买理由 | 依据从开头到结尾实际推进内容的主线，优先选择最贴切的现有选项。在有授权时，可以为已有素材证据支持、后续可复用且现有选项无法表达的形式补标签。 |

常见内容形式的判断：

- **打卡VLOG**：有明确的打卡主题、记录过程或阶段进度，过程本身串起全片。**工作VLOG**按一日行程或工作任务推进，**探店vlog**由实地到店和现场体验推进。
- **产品混剪**：围绕产品依次剪入包装、卖点、操作、试用或不同场景，镜头共同完成商品介绍。**口播**主要靠讲述者对镜推进，**图文**主要靠静态画面和文字推进。
- **带货机制**：以拍一送二、套装、优惠券、限时折扣等为核心购买理由，价格和领取规则主导内容。片尾顺带提赠品或片中闪过价卡时，归实际主线。
- **反差转场**：前后状态对照和切换承担整片的主要表达。**经历分享**按个人经历和变化过程讲述。**教程讲解**以可执行的步骤或方法组织整片。个人经历或教程里的单个对比镜头只是其中的呈现手法。

同一条素材可以是「真人有语音商品展示」加「工作VLOG」，也可以是「真人有语音商品展示」加「带货机制」。记录前三秒的原话或画面、整片的两处代表性证据，再按目标表的选项和单选／多选规则回填。保留原有选项与配置。选项回读确认后再提交记录，并逐条核对回读值和来源身份。
