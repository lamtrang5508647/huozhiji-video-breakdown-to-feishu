# 对话角色与声音标注

目标是让演员和拍摄者拿到脚本就能分工、接话。对话逐话轮标角色，旁白单独标；不把所有文案排成一个人的讲述。

## 先区分来源与新拍安排

- 原片身份只来自可核实的画面、上下文及实际听辨。机器说话人编号、字幕位置或镜头主体不能单独证明是谁在说；不足时写「说话人待确认」。
- 复刻稿可以安排「店主、顾客、主持／拍摄者」等角色，明确这是新拍分工。保持已知人物关系、经历、反馈及承诺的归属，不补造原片人物身份。
- 同一人在不同段落可有不同声音方式，例如店主现场回答，另为产品特写后配旁白；每处分别标。

面向用户的原片转写稿，用「第17段｜谁在说：待核对」这类直白标签，不把「源片编号-ASR-17｜机器说话人1（身份及分段不可靠）」当作主要阅读标题。机器编号保存在来源映射中。每个转写小节集中解释一次：数字只是阅读顺序，自动分段可能混入几个人的话，人物和疑词尚需对照录音确认；同时给出按角色分好的复刻拍摄稿入口。原片核对资料和可拍的新稿要能一眼分清。

## 每个话轮显示什么

1. **角色**：尽量用具体姓名加角色；未知演员用稳定的角色名。多位顾客区分「顾客甲、顾客乙」，不要交替写成同一人。
2. **交流对象**：如店主→顾客、主持→店主、主持→观众。问句与答句逐条排列。
3. **声音方式**：现场对话／现场画外提问／对镜头口播／后配旁白。画外仍可是在现场与对方交流，不自动视为旁白。
4. **台词**：角色标签与可朗读正文分开。仅补角色时，不顺手改写已审台词或变量占位。
5. **必要的接话或动作提示**：如「顾客说完后接」「看向顾客」「举起标签再回答」。提示单列，不混进配音文字；本轮未确认的表演效果不写成已验证。

先给简短角色表，再给连续稿及分场稿。短脚本可直接写：

> 【顾客→店主｜现场对话】呢两款有咩分别？  
> 【店主→顾客｜现场对话】先摆埋一齐，睇清楚标签同尺寸。  
> 【店主→观众｜后配旁白】近镜再睇清楚细节。

新拍提示示例：第一句拍顾客发问，第二句拍店主回应，第三句配产品特写。此例只示范角色排版，不是任何参考片原话。

分场表推荐列为「场景／话轮｜谁讲→对谁讲｜声音方式｜台词｜动作或接话」。已有表结构不必为了这点另建表；在现有复刻建议字段中保留这些可读标签即可。

## 素材表和台词槽

- 「完整台词槽」「句式参考」「仿写文案」中的每一段可说内容都要有角色；包含多人时拆成多行。变量公式仍是公式，不冒充最终完整新稿。
- 段级台词被多个物理镜头引用时，标「所属段角色台词参考」。不要给每个特写重新安排一个说话人，也不要把整段台词标为在该短镜头内全部说完。
- 画面拍手镯、店面或顾客反应时，声音可能来自店主、主持或后配；写清画面主体与发声角色各自是谁。
- 对话中的聆听者不必有台词；没有声音就写「无台词／环境声」，不要为了填满格子编旁白。
- 一人拍摄可提供实际可行的可选安排，例如拍摄者画外提问、店主回答。选项不能改变原稿里谁有这段经历，也不能把多人对话合为一人背稿而不说明。

## 交付前通读

逐场从第一句读到最后一句：谁先问、谁回答、对谁解释、哪处转向观众、哪处为后配，都应直接可见。核对连续稿、分场稿及素材建议角色一致；同角色跨声音方式时明确切换。

核对实际台词逐字保持或另有获准的修改记录。结构检查只能证明标签存在，不能证明角色安排符合现场逻辑；应由审阅者实际读过问答后确认。角色标注也不替代原声听校或实录时长验证。

## 从声画话轮到生成分镜

用于参考复刻、对话视频生产或原创脚本转分镜；只做资料分析时，保留观察记录，不自动提交生图、音频或视频任务。

### 分清四种粒度

- **原片物理镜头**：实际切镜之间的一段画面，保留原编号和源时间。
- **话轮**：一个角色连续发言的自然区间，可包含多句话。换人、重叠发声或声音方式变化时分开记录；停顿和接话空隙保留。
- **图片关键帧**：体现站位、脸向、麦克风、手部或产品状态的必要变化。同一图片可支持多轮对话；是否补图由可见动作和实际驱动需要决定，不机械地一句一图。
- **生成任务**：依据当前接口的单人、多角色、音频和时长能力划分。同一物理镜头可能包含多个任务，不能把这些任务数说成原片的切镜数。

### 先对照原声与连续画面

参考片先按完整音视频核对发声人、问答关系、嘴部动作和麦克风传递，再取覆盖发言前、发言中、发言后的证据帧。单张中点图、自动说话人编号或字幕都不能单独确定角色；声画不一致或不可见时标「画外发声」「嘴部受遮挡」或「待确认」，不编造正面说话画面。无实际听辨能力时保留待听状态。

若使用已确认配音，保留源片时轴与配音母轨时轴的独立映射，不能假设两者等长。原话、转写校对与新稿分开；粤语依原声和已核准用字，不用普通话识别结果推断粤语发音。原创先标计划角色和预估时长，录音确认后才填实际起止；不得把计划当源片观察。

每个话轮至少能追溯以下内容；已有表格可在原字段里分行呈现，不默认加表或重写历史记录：

| 内容 | 需要看清什么 |
| --- | --- |
| 镜头与话轮 | 所属物理镜头、话轮 ID、源视频起止及证据位置 |
| 声音 | 谁讲→对谁讲、声音方式、原台词、确认母轨的起止与文件引用；重叠讲话单独注明 |
| 画面 | 发声者是否在画内，脸向、景别、嘴部可见性/遮挡，另一人的倾听、笑、点头等实际状态 |
| 生产输入 | 人物身份和场景库引用、已有/新增关键帧及补图原因、所需动作状态和可行驱动路线 |
| 核对状态 | 哪些已看画面、已听原声、用户确认；未知项和改编建议明确区分 |

例如同一双人镜头中「主持问→顾客答→主持追问→顾客答」，应有四条话轮；仍可能只需要起始和动作变化的两张图，也仍是一个物理镜头。若主持画外提问、画面只拍顾客，不为填满表格强造一张主持露脸图。

### 从拆解交接到制作

每轮给出说话人的发言段及其他角色的倾听状态，不能把混合对话音轨交给单人驱动后默认其会识别所有人。接口若支持可验证的多角色映射，可以保留整段；否则按自然话轮准备独立驱动素材。裁出单脸、给另一人静音或加入提示词都不等于已解决抢话和口型。

用已确认人物与对应场景准备关键帧，检查换人时的视线、脸向、麦克风、手镯和站位连续；保留招牌的文字、位置与柜体关系。复刻保留参考片切镜；建议增加近景、反打或插镜时说明这是改编，不能冒充原片拆解，也不擅自用商品特写掩盖失败口型。原本侧背或遮挡的角色不强行转正，记录可验性限制。

交付后分开核对角色切换、原音时序、可见唇形、动态身份和场景连续。静态图正确不能证明口型自然；局部运动跟随只处理位置与边缘，不能自动修正错误唇形。技术结构检查不代替声画播放与用户验收。
