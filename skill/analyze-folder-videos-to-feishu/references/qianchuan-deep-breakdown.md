# 千川信息流带货视频：购买决策与声画深拆

用户要求从千川编导角度深入拆解、复刻脚本或整理可剪素材时使用。先完成原文校对、语义段和逐画面来源绑定，再解释原片怎样推进理解与购买决策。这是分析和素材整理流程，不提交广告投放，不生成图片、声音或视频，不自动建立 AI 任务台。

## 学习依据和适用范围

以下设计参考公开可阅读全文的巨量官方案例，并结合现有项目的来源与复核约束。它是本项目的拆解方法，不是平台规定或效果保证。

- [逐本案例](https://agent.oceanengine.com/awardsDetail/17408)：人群/场景洞察、内容规划、生活化表达和测试反馈形成循环。用于提醒分析者连接购买情境与创意机制，而不是把“前三秒”固定成所有原片的段界。
- [科大讯飞案例](https://agent.oceanengine.com/awardsDetail/17513)：从不同价位和购买心理提炼功能，使用口播、实拍、录屏等表达。用于拆“哪项功能回应哪种需求、用了什么表现方式”。
- [珂拉琪案例](https://agent.oceanengine.com/awardsDetail/17353)：特定消费场景与声、画、文结合，同时储备实拍镜头和创意开头。用于拆声画配合与可替换模块；节点策略不可移植为全年规则。
- [猿辅导案例](https://agent.oceanengine.com/awardsDetail/17257)：短视频中的人物、商品介绍和场景与直播承接呼应。用于检查视频承诺与后续入口；未访问承接页时只能记录待核对项。
- [八马茶业案例](https://www.oceanengine.com/insight/816)：明确活动窗口为2022年6月11—18日，素材、货盘、直播场景等同时调整。用于提醒复盘保留上下文，不能把整体业绩变化归因于单个镜头。

前四页未提供可核实的发布日期；珂拉琪正文为兔年春节节点。上述均为历史案例自述，不能当成当前投放规则或控制实验。2021年官方[文案调色盘文章](https://www.oceanengine.com/blog/juliang-qianchuan-baokuan-wenan.html)可作分析视角参考，但不能用其旧颜色定义覆盖本项目 v9 功能分类，也不把按消耗选出的历史样本当成转化因果。巨量学只读到介绍/目录的课程，不标记为已完整学习。

## 六个分析问题

| 维度 | 应回答的具体问题 | 来源与交付 |
| --- | --- | --- |
| 购买情境 | 片中明确对谁说、在什么场景需要、提出什么疑问或顾虑？分析者推断了什么？ | 记录原句/动作和时间；目标人群推测保留推测身份，不恢复已删除的整片受众假设板块。 |
| 开头及信息推进 | 第一项有意义的信息是什么，靠画面、原声、字幕的哪种关系吸引？后面如何回应它？ | 标实际时刻，不按固定秒数硬切。开头位置不等于钩子类别，每段也不必出现商品或 CTA。 |
| 主张与论证 | 原作者说了什么，展示了什么材料，如何连接到结论？还有哪部分未被支持？ | “主张 → 展示材料 → 支持范围 → 未决项”分别写，不把口播、动画、包装、资料截图自动升级成有效验证。 |
| 声画及动作 | 同一范围内听到什么、看见什么、字幕写什么？是重复、补充、演示、反差、冲突，还是仅作氛围？ | 保留原声校对状态、实际镜头和时间。画面切点与句子结束分别定位；无音频证据时不编语速、重音或停顿。 |
| 转化与承接 | 片中引导的是进直播间、看商品、咨询、评论还是别的动作？承接是否一致？ | 区分原片入口与目标平台建议；原片来自B站不代表是千川投放素材。没有访问直播间/商品页或投放数据则标未核实。 |
| 可复用机制 | 什么表达关系能保留、哪些事实/场景必须换、哪些镜头能单独剪、哪些需带前后文？ | 写具体变量、使用条件和窗口；另列可比较的测试假设，默认未测试，不推断素材已跑量。 |

不用统一的“痛点→商品→证明→优惠→下单”倒推原片。先解释实际顺序，缺少的角色不补齐。故事、评议、反问、过渡和自我纠错段可以没有购买回答；说明其实际作用即可。一个主张和限定它的否定、条件、引用必须连着理解。

## 在现有字段中交付深度

不为每条视频再建文档。沿用源视频、脚本段、素材及产品×平台汇总章节；视频原标题 H1、公式/图例/完整语义段 H2 保留。默认不显示 `不可直接照搬`、`整片受众假设（非测量）`、`复刻素材清单`。

| 层级 | 既有字段 | 深拆写法 |
| --- | --- | --- |
| 整片 | authoring `strategy`；manifest `whole_video` | 一句说明切入点、核心信息、信息如何推进、原片行动出口；写清已知与未知。 |
| 本段问题 | authoring `question`/`role`；manifest `core_question`/`role` | 本段回答的具体疑问和承担的具体作用。不能只填“建立信任、促进转化”。 |
| 论证与声画 | authoring `structure`；manifest `source_structure`、`source_claims`、`source_evidence`、`shot_groups[].source_observation` | 依次写原句/动作、声画关系、论证连接和支持缺口；引用源镜头和当前语义段时间。 |
| 可复用内容 | `reusable_formula` 与 authoring `formula`/`slots`/`conditions` | 保留关系，替换事实；变量需要什么本品资料，缺资料时怎样改成有依据的表达。 |
| 可剪窗口 | `source_shot_spans`、authoring `shoot`/`conditions` | 主体与动作、有效起止、接前/接后的必要语境、原字幕/口型/声音限制；建议剪点与已经验证的切片范围分开。 |

深拆章节调用现有渲染器时设置 authoring `analysis_mode: qianchuan_deep`，原片段落仍按原顺序呈现。该模式额外显示整片策略、本段问题/作用、论证与声画关系、复用条件；程序核对本段问题、作用及论证/声画字段与 manifest 一致，整片策略和复用条件的含义仍须内容复核，不能在排版时临时改写源分析。旧章节缺省排版保持兼容。颜色仍只表示短语脚本功能，不能同时用来表示情绪或证据可信度。

`source_evidence` 为可选数组；每项包含 `source_video_id`、`source_sha256`、`source_shot_ids`、`start_ms`、`end_ms`、`description`，可附 `support_scope` 和 `verification_status`。时间为当前段内的整数毫秒半开区间，引用对应镜头的真实交集，不能借另一个视频或邻段材料。状态只允许 `unverified` 或 `source_material_only`，表示记录了源片材料而非已经独立验证；内容正确性仍须看原片。没有该数组时，既有“呈现的证据”字段必须明示缺少材料记录，并单列原作者主张，不自动从主张生成论据。

升级后需从已复核的输入重新构建上传计划，并核对新的计划哈希；旧计划中的主张与材料展示文字可能不同，不沿用旧哈希或放松写回检查。已有源片、记录和业务键保持可追溯。

## 情绪在叙事中解释，不强补转折

按实际原句、语气、动作和信息变化，说明情绪表达怎样参与本段推进。人物内心、观众实际反应和投放效果分别保留未核实边界；“专业”“痛点”“信任背书”不是自动可用的情绪标签。

新数据在 segment `emotion` 内使用 `progression_status`、`review_note`、`observable_timeline`；authoring section 对应 `emotion_progression_status`、`emotion_review_note`、`arc`：

- `observed_changes`：至少两个真实有来源的事件；记录实际变化，不限定四阶段。
- `no_clear_change`：至少一个定位明确的观察；说明本段没有清楚的情绪转折。
- `insufficient_evidence`：明确复核缺口；可无事件，展示待复核，不能变成“已审核通过”。

事件沿用当前毫秒、观察原文和镜头引用。旧数据没有状态时继续兼容已审的四阶段结构；新分析不为通过旧格式编造触发或转折。

## 复用与测试的分界

每条复用建议写成“保留的表达关系 → 可替换变量 → 必须补的事实/素材 → 使用条件”。一个独立镜头若丢失否定、对比对象、产品身份、日期或下一句限定，就标需带前后文，不为了素材数量拆碎。

测试建议记录待验证假设、改变的变量、尽可能保持相同的条件、观察指标和无法归因的因素。优先比较开头切入、同一卖点的证明方式、声画组合或承接，而不是同时换商品、价格、人群、文案和入口后宣布某个镜头有效。有实际报表才填结果，绑定准确视频/创意ID、商品、转化目标、日期、样本和后台指标口径；高点击与高成交分别分析，不能由点击变化直接推断购买效果。未投放的建议一直标“未测试”，本流程不创建广告计划。

## 较小模型的交付与复核

逐段交“时间与镜头 → 原句/动作 → 购买问题和声画关系 → 主张与材料及支持范围 → 有条件的复用建议”。模板承载分析，不能用关键词判含义或复制泛泛段落。先交一个普通段和一个有否定/引用/声画冲突的难段，独立复核后再展开。

程序检查来源哈希、真实交集、精确文字、状态、字段一致性和保存结果；监督者裁定意义与材料匹配。缺音频、承接页、产品事实或效果数据时写具体缺口。此参考和测试通过不代表真实原片已经重新听校、全库已经改写或千川投放效果已经验证。
