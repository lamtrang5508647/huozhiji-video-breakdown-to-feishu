# 将代表镜头整理为 AI 素材任务

当用户明确要求新建产品素材任务子表时使用；日常拆解仍复用原素材资产库，不自动复制全库。先区分“整理待生成任务”与“提交生成”：前者不调用生成服务，不因创建任务而启用模型或计费。

## 一条任务对应一个代表镜头

同一 Base 内建立用户指定名称的任务表，先查重并保存表 ID。核心列：素材名称、素材视频（附件）、产品（业务分类）、镜头标签（多选）、倒推AI提示词（文本）、产品参考附件（附件）、生成视频附件（附件）。另保留生成状态、质检结果、原始镜头（单向关联原素材）、稳定素材编号、画幅、目标时长和来源与适配说明；模型及任务 ID 可隐藏但应留作提交后查重。

代表数按本轮要求，不自动扩展。优先选互补的工作、学习、娱乐、社交、洗护与商品动作，独立表情包不作为默认生成批次。关键帧只辅助阅读，不代替「素材视频」。如用户要求新表有可预览的参考视频附件，允许只上传选定代表，保留原记录、原附件和关联，不将此例外扩大成全量重复素材表。

## 按镜头写提示词

逐条看对应片段证据，记录实际帧或播放范围；抽样三帧只能说明看过采样帧，不能声称完整动态/音频审过。来源保留稳定素材 ID、实际画面编号、原片时间和本地文件哈希。短于1秒的参考扩成5秒是拟拍方案，不能称为原片完整动作复述。

具体写主体、场景、景别、构图、动作顺序、光线、镜头运动和目标时长。标签分具体场景、可见对象、景别/拍法、编导用途，不能用「生活」覆盖工作、书写或手游。实际看到梳子分缝不能标剪发；已开瓶颗粒展示不能称为完整开盖动作。生成方案改变动作或镜头组织时，在提示词或适配说明里说清原片与拟拍的区别。

产品归类不证明真实品牌、SKU、包装或剂型。露包装任务必须以本品参考锁定真实产品形状、色彩、商标与文字布局；不复制竞品瓶型后只换名字。不见本品内容物不能默认黄色胶囊、粉末或液体。无参考可完成任务整理，保持「待补产品参考」，条件提示词执行前需据真实附件定稿。用户可以之后在该列自行上传，执行者下次需读取并查看附件，不凭「已上传」自动认定匹配。

无产品露出的情境镜头可以先整理，不强行植入商品。原游戏录屏/影视脸换原创主体和底片；资料、价格、认证及效果数据使用实际核对资料。机理动画只借表达方式，科学结构先核对，不把原片收缩或增长动画重制成我方效果证据。已确认的不适合自由生成的镜头可以保留任务并注明实拍/设计建议，不需要为凑生成数量伪造结果。

## 状态及验收

- 待生成：提示词和来源已整理，未提交，不表示模型能力已测试。
- 待补产品参考 / 待核对结构：记录具体缺项，仍不提交。
- 生成中 / 待质检 / 可用 / 需返修 / 失败：仅按真实任务与结果更新。

生成前另落实用户选择的服务、模型、预算和提交授权；用户说暂不提交时保持生成附件、模型和任务 ID 为空。生成后检查动作接触关系、手指/头发、包装及人物连续性；未生成的质检列写「尚未生成＋验收要求」，不能填成通过。

先两条代表记录写入和回读，再展开本轮批次。Base 操作串行；字段选项先创建并实时核验。创建及上传不确定时先回读查重，不盲重试。核对每条提示词完整值、标签、单向来源关联、附件名/大小、状态，确认老素材所有记录与原字段保留。画廊视频附件封面和字段顺序须读回；API 配置通过与用户实际播放是两项验收。

项目保存 `config/ai-materials.json`、`state/ai-materials-index.json` 及回读证据。下次优先复用已建任务表，按稳定来源＋版本键防重复；若有人改了提示词或上传参考/成片，先比较，不用首批计划清空人工附件或覆盖修改。
