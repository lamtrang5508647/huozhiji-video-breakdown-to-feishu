# 素材库：剪辑复用与 AI 重制

用户要整理素材库、筛选复用镜头或为视频模型准备参考时使用。本流程只分类与提供重制要点；未明确要求生成时，不提交付费生成任务。

## 两个独立结论

`剪辑复用` 判断现有文件可用在什么语境，不能从下载成功推导商业授权。
`AI重制` 判断镜头形式是否适合重新制作，不能把“适合生成”写成“已测试生成成功”。

在已有素材表中使用以下字段，实时读取字段和选项；授权整理标签时才补缺失字段，再回读确认。不新建素材表或重复视图。

| 字段 | 类型 | 定义 |
|---|---|---|
| 素材主题 | 多选 | 实际可见的对象，如掉发发丝、洗护梳理、产品包装、成分食材、机理动画、文献专利、人物口播、反应表情、生活情境、发量对比、图文标题 |
| 剪辑复用 | 单选 | 条件复用 / 仅限原片语境 / 仅作参考 / 待复核 |
| AI重制 | 单选 | 优先重制 / 需参考约束 / 建议实拍或设计 / 不宜生成证据 / 待复核 |
| 调用标签 | 多选 | 开场钩子 / 痛点代入 / 原理解释 / 成分展示 / 产品展示 / 使用演示 / 过程记录 / 变化观察 / 资料引用 / 价格优惠 / 互动收尾 / 转场反应 |
| 身份与画面限制 | 多选 | 如原字幕需替换、人物需替换、品牌需替换、名人或影视素材、真人效果自述、效果对比、真实资料不可编造、机制仅作示意、动作连续性、短于1秒 |
| 复用条件 | 文本 | 具体可用用途、需核对或替换内容、源素材授权状态 |
| 重制要点 | 文本 | 本镜头的主体、景别或构图、动作，以及必须保持/替换的元素 |
| 复用审核 | 单选 | 画面已核对 / 需补看动态 / 待核对 |

`条件复用` 不是无条件直接剪用；需取得源素材授权并处理字幕、水印、声音与上下文。
`不宜生成证据` 用于真实效果自述、DAY进程、前后对比等。并不禁止改为中性情境或借用版式。
普通提问、反应和解释口播可以换原创出镜者重做，不应一律判成效果证言。
文献、证书、聊天、订单、售价和包装文字使用核对过的真实资料，优先实拍、录屏或后期排版。
竞品包装可借鉴镜头形式，但目标产品必须有自己的参考图，不能只换文字留下竞品瓶型。

## 千川编导选材与表情包归档

用户要求从千川编导角度优化时，另用四个字段记录选材判断。`AI重制` 是制作方式，不能代替投放脚本中的价值和优先级；技术上容易生成的表情包不应因此排在商品镜头前面。

| 字段 | 类型 | 选项或内容 |
|---|---|---|
| 选材分区 | 单选 | 核心带货素材 / 辅助说明素材 / 表情包归档 / 原片记录参考 |
| 编导用途 | 单选 | 痛点开场 / 商品亮相 / 使用展示 / 成分展示 / 原理可视化 / 证据展示版式 / 体验记录拍法 / 价格承接 / 下单引导 / 解释口播 / 生活过场 / 情绪转场 |
| 选材优先级 | 单选 | 优先拆拍 / 按脚本选用 / 只借鉴拍法 / 低优先归档 |
| 编导调用建议 | 文本 | 本格可见主体与景别 → 新稿脚本位置及功能 → 具体拍法/制作方式 → 本格替换和取舍；相似镜头可指向优先参考的同视频画面编号 |

这些是编导建议，不是已验证的留存或转化结论。未知投放效果不得填成好素材、爆款或高ROI。

1. 独立表情包、影视反应、趣味彩条与综艺时间卡归档，优先级设为低优先；剪辑复用降为仅作参考，AI重制改为建议实拍或设计并说明默认不投入生成。普通简洁时间字卡可留辅助分区。保留原记录、附件、编号、时间与来源关联，未经具体删除授权不删除原片段；标签归档不是释放附件存储。
2. 主体是掉发、地漏、产品、服用动作等实拍，只叠一块表情贴纸时，按实际主体与脚本作用判断，不能因出现表情整格归档。制作建议说清如何去掉贴纸/原字幕、换原创主体。
3. 重点选择能交代困扰、商品、真实配方、具体动作、清晰说明、价格条件与下一步的镜头。核心分区不意味着每条优先拆拍；同类持瓶/吞服/DAY镜头只选少量清楚且互补的代表，其余按脚本选用。不同景别/动作可保留为替换候选，不能仅因主题相同判成可删重复文件。
4. 资料、专利、奖项、报价、成分表、聊天及AI页面只借版式，不互相充当真实证据。公众人物、医疗过程、作者周期记录和效果对比留原片研究；不得生成我方结果。原理与配方关联仍须核实，不由原片主张自动背书。
5. 业务产品分类与原片可见品牌分开。目标产品包装、款式、胶囊形态、剂量、标签必须用本品资料；千川下单引导按实际商品组件制作，不能直接搬B站评论区链接和其他平台标志。
6. 复用已有产品×平台画廊：保留原过滤条件与视频附件封面，追加 `选材分区 disjoint [表情包归档]`；按选材优先级、原来源、画面序号排序。现有管理网格保留全记录，按产品、分区、优先级分组；不新建同名表或重复视图。其他全部镜头时间线视图不改成选材排序。
7. 先快照、绑定源身份、审核代表小样，再全量写入并回读；回读逐条比对新增字段、归档修改和所有原字段，云端统计与完整分页结果对账。原有需补看动态状态不能因添加编导建议而升成已核对。记录被归档不等于素材交付缺失：采用显式 `verify_material_gallery.py --archive-zone 表情包归档`，校验当前画廊确有该排除过滤，并分别验证可见与归档片段的附件及来源/段落关联。默认不传参数仍要求所有计划片段可见。

## 场景标签：大类与细分

用户要求细分工作、学习、生活、运动等场景时，在原素材表补充 `场景大类` 与 `场景细分` 两个多选字段。已有素材主题是对象分类，编导用途是脚本功能，都不能替代具体场景。按已读的实时选项写入；同一镜头有两个实际分屏场景时分别多选，不另建素材记录。

| 大类示例 | 细分示例 | 判定边界 |
|---|---|---|
| 工作 | 电脑办公、办公交流、办公室记录 | 场地在办公室不等于动作在办公；服用/拍头发应同时标具体动作与办公室记录 |
| 学习 | 阅读书写、资料查阅 | 真人看书写字可直接判断；只有论文/GPT截图或表情角色看书，不算真实学习场景 |
| 生活 | 床上刷手机、沙发刷手机、电脑游戏、手机游戏、躺卧休息、休闲棋牌、镜前自拍 | 电脑不能一律标工作；手游与桌面游戏分开；不能把所有真人画面都归生活 |
| 运动 | 跑步、力量训练、球类运动 | 当前没有看见运动则只预留选项，不补成已存在素材 |
| 饮食社交、出行 | 外卖餐食、吃饭用餐、聚餐举杯、街头行走、飞机交通、电梯过场 | 清楚区分具体活动；不凭餐盒推断节食，不凭举杯推断病因 |
| 洗护打理、产品使用 | 洗头、地漏清理、吹发、理发、开箱、取胶囊、吞服动作 | 只写实际动作；举瓶到嘴不等于胶囊吞服；持盒讲解不等于服用 |
| 医疗检查、口播讲述、非生活场景 | 医院登记、头皮检测、室内讲述、资料截图、图卡、表情转场 | 医疗记录不泛归工作/学习，口播不默认生活，表情角色的虚构场景不进入真实场景素材筛选 |

细分选项使用 `大类｜细项` 便于搜索。不同大类可以共存，但每个细项都须映射到对应大类；保留 `待核对｜电脑用途未明` 等明确不确定项。场景标签是画面及原片叙事语境分类，不证明真实身份、时长、因果或效果。暗光不自动等于熬夜，键盘不自动等于加班；若采用原片明确配字的工作语境，在审阅理由里注明来源，不能升级为已经核实的真实经历。

逐条审源描述与相关实图，保留源ID、实际画面编号、判断理由和实际看过的证据；字段联动、格式及查重程序只校验人工决定，不代替视觉判断。将两个字段加入现有画廊和管理网格的可见字段，保持过滤、排序、分组、视频封面和归档规则；不清空原有字段。小样→批量→完整分页回读与云端多选聚合对账，多选计数可重叠。保持原有动态待审状态。

`sync_video_base.Lark.fields()` 遇到 CLI 的 `truncated` select 选项时，会串行分页 `+field-search-options` 取全，再进行选项校验；`+field-list` 和部分 CLI 版本的 `+field-get` 可能只返回前 50 个。不能把摘要截断误认为字段选项没创建，或凭截断配置全量覆盖字段。

## 证据与审核

1. 保存当前字段、视图、完整分页记录。用素材ID+原视频关联+时间+附件文件名绑定本地片段与已审时间线，校验可用的文件哈希。空行不补成素材，缺失片段保留待核对。
2. 逐条看对应关键帧与来源描述；联系表必须显示实际素材序号，并保留素材ID、时间和来源视频。不要用旧候选切点序号直接写当前素材。手口操作、头发/手指变形、镜头运动等依赖动作判断时补看连续帧或播放，未看则标需补看动态。关键帧审核不是音轨、版权、效果真实性或动态成片验收。
3. 分开判断画面主题、原片脚本作用、重新调用的用途。画面里提到某物不代表看见它；人物照片不是口播，单张头顶不是前后对比，舞台反应不是源作者证言，结束卡不是论文页面。只有看见或源证据确证的身份/品牌才具体命名。
4. 较小模型逐行提交源ID、素材ID、实际看过的证据、八字段和观察理由。监督者独立抽看，裁定争议、跨视频检查同类标准；先用不同类型的小样验收再批量。不能把关键词规则分类或拼接旧描述冒充逐图审核。
5. 重制要点必须能指向这一镜头。不要套“保持头发/手部/物体/机理连续性”到不相关的画面，不复制“漏检补帧”等实施注释，也不把所有口播打成同一功能。模板只能承载确定字段，不代替判断。

## 写入与回读

只更新复用字段，保留原文件、字幕、时间、所属产品/平台、原视频与脚本段关联。按素材ID和record_id更新，禁止另建同样素材或重复上传文件。

Base API 串行执行：实时schema校验 → 少量代表行写入 → 回读全部字段及原附件关联 → 批量更新 → 对每条计划值回读比对。写入回执不等于落库验证。Select选项必须先存在，字段配置更新保留现有完整属性。

复用既有产品平台画廊，在卡片显示主题、剪辑复用、AI重制、调用标签与审核状态；长说明在记录详情/现有管理网格中看。保留视频附件封面、产品平台过滤与已有导航。可调整已有网格的字段顺序和分组，不复制新入口。

状态文件记录实际覆盖数、待动态复核数、审核证据哈希、回读结果和使用的视图。后续同一素材输入未变时保留人工修订；源片、切点或语境改变时重新审核，不按标题覆盖。

这套素材字段不恢复用户删除的脚本文档板块：`不可直接照搬`、`整片受众假设（非测量）`、`复刻素材清单` 仍保持默认隐藏。
