# 镜头与语义段的时间交集检查

`source_group_spans` 是镜头与语义段的时间交集信息，和镜头唯一的主归属 `group_id` 是两个不同概念。镜头 0–1200 ms 如果跨越语义段 G01 的 0–1000 ms 和 G02 的 1000–2000 ms，它可以仍以 G01 为主归属，同时交集应分别记录 G01 的 0–1000 ms 与 G02 的 1000–1200 ms。这个检查不会更改主归属，也不会写入多维表格或为其他数据结构制造多主归属。

已有时间线包含 `source_group_spans` 时，可选运行独立检查；在本 skill 目录执行：

```bash
python scripts/check_shot_group_intersections.py --timeline <timeline.json> --output <new-report.json>
```

输出文件可省略；如指定，必须是不存在的新文件。检查器只读取时间线，并计算其中每镜的 `[start_ms, end_ms)` 与顶层 `semantic_groups` 的时间交集，按毫秒精确比较段 ID、起止时间和数量。语义段须有唯一 ID、非重叠时间，并完整覆盖提供交集的镜头；时间缺口或关联不一致会阻断检查。`source_group_spans` 中的 `id` 如果存在，必须和所属镜头 ID 一致。

- `PASS`（退出码 0）：每镜都提供字段且全部精确匹配。
- `PARTIAL`（退出码 2）：只有部分镜头提供字段，已提供的字段匹配，但不能代表完整通过。
- `NOT_PRESENT`（退出码 2）：所有镜头均无此字段；兼容旧数据，不虚报通过。
- `BLOCKED`（退出码 1）：输入异常、交集不符、语义段重叠或未覆盖。

结果只证明**输入所声明的时间数据之间一致**。它不核实实际源文件、画面、声音、字幕或语义段边界的真实性，也不批准发布或写回；报告始终标注 `source_file_verified: false` 和 `publication_ready: false`。单个镜头的 `PASS` 不能替代全片状态。旧时间线不因缺少可选字段而被改写或自动升级，现有正式导出和 Base 规划规则不受此脚本改变。当前 Base 规划使用唯一主归属，不要把跨段交集直接转换为多个语义段的主镜头成员；如需要其他关联，须由目标数据结构单独支持和验证。
