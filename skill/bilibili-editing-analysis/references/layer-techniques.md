# 多风格剪辑：分层观察与重建参考

本页是备选方法，不是一条必须套用的剪辑公式。先看真实参考片，保留它的内容结构、信息量和声画关系，再选择实际出现的手法；同一平台的视频可能是口播、记录、资料拼贴或混合形式。以下图层只是**可行重建方案**，不代表原工程的真实轨道或插件。

## 先记录，再实现

对每个值得复刻的事件记：源片起止或可确认的时间范围、关联脚本和画面、屏幕位置与大小、前后变化、遮挡关系、持续时间、观察方式及证据文件；音频单列“已听校／未听校”。提供素材入口并区分“现有可用”“参考原片”“需要补拍或制作”，然后写新项目的图层、操作顺序和可调整参数。多个对象同时出现时画出前后层级；跨多个源区间分别记录。将描述放进 [分轨事件模板](editing-events-template.md)，按 [剪辑师交接](editing-handoff.md) 关联对应素材。

旧总览图和候选时间线需要核对来源与实际解码 PTS：图上的目标时间不一定等于显示帧的真实时间。若图与对应原片时刻不符，保留两者及偏移证据，重新从确认哈希的原片取帧；在成因核清前不要断定串片，也不要仅凭总览图批准精确剪点。

一张静帧能证明的是该时刻可见的布局、文字和图形，不能证明运动、入场方式、切点、持续时间或伴随音效。要判断变化，先检查带原始时间戳的前后帧及变化过程；判断听觉、口播衔接和卡点必须实际收听。样本之间只确定变化发生的窗口，逐帧也只确定所观察的帧界，不代表完整观看。无法核实的插件、缓动、字号或精确时长标为未知或待调，不要用估计值冒充原工程参数。

## 实际出现时可选的重建方式

### 多图对比与人物拼贴

**观察**：各图的数量、并列或先后出现、比例、裁切、标注位置，以及画面变化前后的真实时间。静帧不能证明它们是同时入场还是依次出现。

**重建**：底层铺背景；将每张图片或视频分别放上层，裁切到两栏、多栏或自由拼贴；日期、名称、箭头与字幕分别建层，必要时分图设置位置和缩放关键帧。以实际字幕节奏留足阅读时间。确认素材本身可用，对比使用条件按新项目实际素材确定。

### 主体口播与画中画小窗

**观察**：谁是主画面、小窗在何处、外框/遮罩及遮挡、内容是否替换，分辨小窗是否叠在同一底画面上；口播文字与音频对齐待听校。

**重建**：口播放底轨或主轨，补充内容放上层；用缩放与位置、圆形或圆角遮罩做小窗，单独设边框与阴影，底部字幕留出可读区域。信息切换时只替换小窗素材可保持主体连续；原片是否这样制作仍需依据证据判断。

### 字幕与局部强调字

**观察**：记录实际可见文字、断句、颜色、位置、何时出现/消失；完整口播与字幕不同步、遮挡或听不清时标注不确定。逐字出现必须有连续画面证据，不能据单张字幕图断言。

**重建**：基础字幕与强调字分轨，按实际配音时长和阅读速度分句，重点字可单独设置颜色、大小或运动。只用已经核对的文字；原音未听校时标为字幕摘录，逐字动画、节拍和音效待核。最终时长以实际录音为准。

### 裂缝、遮罩和形变过渡

**观察**：记录遮罩第一次可见、大小或形状变化、最后一次可见，以及遮挡前后画面是否变化；放大看相邻帧和其间全过程。不能仅凭黑色图形断言镜像、翻页、速度曲线或特定插件。

**重建**：底层放前后画面，上层放透明底的图形或形状遮罩；先确定遮罩出现和消失，再用位置、缩放或遮罩形状关键帧调整覆盖；如确实需要镜像或形变，另建复制图层并先用短样本检查衔接。源片无法判定的参数由剪辑师试做，不视作原片参数。

### 信息卡、截图与关键词递进

**观察**：逐项记卡片数量、背景是否虚化、位置、可见文字、卡片出现的先后顺序，以及底层画面是否持续。不同卡片出现不一定是新的场景切点。

**重建**：保留人物或背景底层，按需要叠加模糊副本；每张图卡及其标签独立成层，依照已观察的顺序安排起止，字幕保留可读空间。资料截图的来源与新项目内容分别核验；入场动效及音效未证实时不写成事实。

### 日期进度与使用过程

**观察**：区分日期角标、主画面、前后并列与视频中的个人叙述；记录各标签首次可见和画面更换范围。日期标注不独立证明体验或结果。

**重建**：将不同日期素材按真实时间排序，角标、说明和字幕独立；可使用连续单画面或并列对照，不强制固定天数。若新素材、场景或光照不可比，应在交接表标明而不是人为补造变化。

### 叠图、图解与强调图形

**观察**：先区分原图、文字、箭头、圈线、颜色块或其他图形；检查它们与背景的相对位置以及何时首次出现。只看到某一帧时，不推定圈线是手绘动画或图形随着人物跟踪。

**重建**：底层放原画面，图解、箭头、圈线和关键词各自分层；需要突出细节时添加局部放大或遮罩，避免遮住主体与字幕。确认连续帧后再设置位置、描边或显隐关键帧；具体资料与表达以新项目提供内容为准。

## 交给剪辑师的最小说明

每个事件写成“源时间和素材入口 → 直接看到的内容及证据 → 目标图层与动作顺序 → 待调参数和缺口”。同一镜头上的画面、字幕与音效可并列多个事件；无声音证据就留未听校。不同视频的素材密度、剪点和情绪可能完全不同，未经逐片检查不要迁移为统一节奏或宣称转化效果。
