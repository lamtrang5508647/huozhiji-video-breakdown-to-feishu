# 视听证据窗口与审阅清单

先确认本机有 Python、PyAV、Pillow 与 FFmpeg，准备干净的新输出目录：

```sh
python scripts/prepare_review_windows.py --input <原视频> --output <新的本地目录> --window-sec 10 --fps 2
```

工具逐窗口生成接触表、时间戳（目标秒及实际解码 PTS）、原速音频片段（PCM 16 位，保留源采样率和声道数）、源和各证据文件的 SHA-256，以及 `manifest.json`。它不会发送数据或判断内容。源文件和输出不应纳入公开仓库。为避免资源失控，单次最大 30 分钟、3600 张采样帧，每窗口最多 200 帧；不同设备的运行时间不同。窗口中没有采样帧必须人工处理，不得视作无画面。

音频记录包括输出 WAV 实际样本数、时长、源音频解码 PTS 覆盖区间及状态 `complete`（窗口覆盖完整）、`partial`（覆盖有缺口或输出不足）、`empty`（无样本且无已知来源覆盖）、`unknown`（时间信息不足或输出与来源不一致）。允许的时间戳/样本边界误差记录为 `coverage_tolerance_sec`。无音轨仍为 `no_audio_stream`；有样本的静音仍是有音轨，不等于空音轨。覆盖信息不判断声音内容，不证明输出 WAV 内部对齐绝对无误；音频仍须实际收听后才能标记已审。

## 本地交互审片

可由具备视听能力的审阅者在支持 Web Crypto 的本机浏览器打开 `assets/local-review.html`，分别选择**原片文件**和窗口工具输出的 `manifest.json`。页面本地核对原片 SHA-256 和可播放时长，再按每个区间跳转、播放、填写画面审阅方式、音频听校状态和备注。选择“已听校”等状态是审阅者主动声明；页面无法自动确认其是否看听、结论或复刻步骤是否正确。关闭页面前使用「导出审阅记录 JSON」，原清单和原片不被改写。导出含原始事件记录，可再次导入继续编辑；保管这个文件，浏览器页面不做云端保存。页面不发送网络请求；浏览器视频解码取决于系统格式支持。原片超过 512 MiB 会拒绝读入，JSON 最大 5 MiB；请使用其他本地播放器或保持与原片可追溯对应的轻量审阅副本。

也可手工准备事件清单。时间是原片绝对秒数，每个事件的范围独立，不强制连续；`source_sha256` 必须是原片的实际 SHA-256：

```json
{"schema":"bilibili-review-events/v1","source_sha256":"<64位小写哈希>","events":[{"start_sec":0,"end_sec":2.4,"title":"开场字幕"}]}
```

页面在 SHA 不一致或事件超出时长时禁止定位与导出；播放器不支持某格式时不要声称已播放。播放、听校、分层复刻建议仍由审阅者实际完成。导出记录为 `bilibili-manual-review/v1`，保持 `source_record` 以保留原窗口的覆盖信息；手工状态和备注不能自动证明来源音频覆盖或某特效存在。

**采样证据不等于完整播放。** 接触表用于定位候选变化，按实际画面事件回到原片看连续片段或逐帧确认；音频片段生成不等于已收听。模型不能接收音频时保留未听校，不能用转写声称听过背景音乐或音效。需更精细观察时调高采样或另取证据；时间精度以实际 PTS 为准。工具要求容器起点已知且为零；视频流可为已知的非负起点，首解码帧应匹配流起点，记录的是容器坐标下实际 PTS，绝不把晚起的画面首帧改写成零。音频窗口工具仍要求首音频流起点为零；非零、负或未知音轨起点，以及未知或负视频起点，均拒绝而非猜测对齐。逐帧工具只处理视频，不推断音轨同步。用播放器、原时间线或其他媒体分析前先核对时间坐标；工具不证明声画同步。

对遮罩、切点或字幕动态等需要细查的局部，另取原视频连续解码帧（开始秒包含、结束秒不包含，区间最多10秒/600帧、总计3亿像素；超限需缩短区间）：

```sh
python scripts/prepare_detail_frames.py --input <原视频> --output <新的本地目录> --start-sec 12.5 --end-sec 14
```

工具保留每帧原始画面尺寸、原始 PTS、时间基、原片秒数和文件哈希，附接触表；当前仅支持容器与视频流零起点。清单初始状态仍是未审阅。该工具不读取或听取声音，且生成帧不代表用户端已连续播放。按 [分轨剪辑事件模板](editing-events-template.md) 记录实际观察及可复刻步骤。

## 每个时间窗口

独立记录源哈希、时间范围、实际视觉和音频观察方式、已复核及未复核子区间。先完整播放或标注做不到，再看变化附近的连续画面。收听人声、音乐、环境音、音效及它们和剪点的关系；听不到就写待核，不依据波形或字幕猜声音。

记录事件：起止时间/持续时间、类型及画面层、关联镜头和脚本、具体变化、实际视觉/音频依据、复刻步骤、所需素材及开放参数。图片运动/蒙版/变速/过渡要结合连续画面，字幕静止画面不代表出现动画。无法区分观察和猜测时，明确写推测；无素材、无声音不代表原片不存在。写清窗口覆盖及缺口，用户可据此复核。对适用的节奏指标仅使用实际确认的镜头表，时间线格式校验不能代替视听审核。
