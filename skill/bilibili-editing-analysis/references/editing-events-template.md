# 分轨剪辑事件模板

针对实际出现的画面、声音与效果建立时间轴；每一行或每一个事件可使用以下字段。按内容需要增减类别，不要把某个案例的技巧当成所有 B 站视频模板。

## 阶段覆盖清单

先根据真实内容划分阶段，逐阶段检查以下维度；同时补充本片实际出现的新手法。此清单是排漏工具，**不是要求每种手法都出现**。下表同一单元格列出的维度在实际填写时应逐项拆行，各自填写状态与证据，不能用一个状态概括一组。视觉与音频的检查范围和状态独立填写；声画衔接只有双方及其时间关系均有证据时才能下结论。

| 阶段及源时间 | 维度 | 状态 | 实际检查范围和方式 | 证据及缺口 |
| --- | --- | --- | --- | --- |
| 每个实际阶段 | 镜头节奏/时长；构图/运动；剪接/转场；字幕/图形；特效/合成 | 已观察到 / 未观察到 / 待核 | 视觉连续观看、局部逐帧、抽帧等；写对应范围 | 源 PTS、证据路径或记录；未检查范围 |
| 每个实际阶段 | 人声、配乐、环境音、音效 | 已观察到 / 未观察到 / 待核 | 分别写实际收听范围；不能听就写未听校 | 音频证据或审阅者声明及覆盖缺口 |
| 每个实际阶段 | 声画衔接与节奏关系 | 已观察到 / 未观察到 / 待核 | 写同时具备画面和声音证据的范围 | 剪点、声音变化与时间依据；不确定项 |

- “已观察到”只对证据所覆盖的范围成立，列出具体内容与时间；样本能证明样本时刻的可见内容，不代表阶段或整片已完整审完。
- “未观察到”仅在该阶段、该维度已充分检查且没有发现时使用；只抽少量帧、未听音、覆盖不足或看不清都填“待核”，不推断全片不存在。无音轨是媒体检查结论，与有音轨但未听校或静音分别记录。
- 审阅者声明已播放、已听校应保留声明人、范围与方法（可用匿名角色），不标成工具自动核验。自动提帧、波形、字幕或转写不等于观看、听校或声画同步验证。
- 用阶段清单标明待核维度和未覆盖区间；单个事件有证据，不等于其他维度也已完成。现有 `editing-events/v1` 交接脚本只检查输入结构，阶段清单需作为独立附表交付，不声称程序自动验收。

## 分轨事件

| 字段 | 填写方法 |
| --- | --- |
| 视频身份与源哈希 | 标识本视频和原文件；精确帧保留原片时间，不把裁剪片的零秒冒充原片零秒。 |
| 开始、结束、时长 | 原片秒数；证据只能定位窗口时写范围，不伪报精确值。 |
| 对应脚本与素材 | 原句、段落、镜头编号、可用素材入口；缺失就标待找。 |
| 类型、所在轨道/层 | 底画面、字幕、图形、遮罩、图片、BGM、音效或其他；观察到的合成结果不代表已知道源工程轨道。 |
| 观察和证据 | 画面内容、位置、颜色、大小、方向、前后帧、具体时间及观察方式；音频未经听校则写未听校。 |
| 复刻操作及参数 | 讲清素材、层级、顺序、可调时长/关键帧，区分可实现方案与源工程未知参数。 |
| 状态与缺口 | 已直接观察、根据样本推测、未核实；未实测的新口播长度标估算。 |

不同步发生的素材分别列事件，多个图层可同一时间并行。连续帧序列用于核对画面变化，不能证实用户端完整播放、实际听音、插件名称或最终成片表现。

对于动态字幕、转场、图解及特效，按实际素材记录：①可见对象与前后层级；②首次可见、变化和消失的精确帧或证据窗口；③位置、大小、透明度、方向、遮挡等观察到的变化；④以新素材为输入的具体层级顺序和可调整关键帧、时长、速度。把“原片直接观察”“可能实现”“待核/待调参数”分开；缺连续证据时不要编造入场方式、运动曲线、特定插件或声效。某手法未出现时不必添加对应事件。
