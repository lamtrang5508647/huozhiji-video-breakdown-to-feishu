# 分轨剪辑事件模板

针对实际出现的画面、声音与效果建立时间轴；每一行或每一个事件可使用以下字段。按内容需要增减类别，不要把某个案例的技巧当成所有 B 站视频模板。

| 字段 | 填写方法 |
| --- | --- |
| 视频身份与源哈希 | 标识本视频和原文件；精确帧保留原片时间，不把裁剪片的零秒冒充原片零秒。 |
| 开始、结束、时长 | 原片秒数；证据只能定位窗口时写范围，不伪报精确值。 |
| 对应脚本与素材 | 原句、段落、镜头编号、可用素材入口；缺失就标待找。 |
| 类型、所在轨道/层 | 底画面、字幕、图形、遮罩、图片、BGM、音效或其他；观察到的合成结果不代表已知道源工程轨道。 |
| 观察和证据 | 画面内容、位置、颜色、大小、方向、前后帧、具体时间及观察方式；音频未经听校则写未听校。 |
| 复刻操作及参数 | 讲清素材、层级、顺序、可调时长/关键帧，区分可实现方案与源工程未知参数。 |
| 状态与缺口 | 已直接观察、根据样本推测、未核实；未实测的新口播长度标估算。 |

不同步发生的素材分别列事件，多个图层可同一时间并行。连续帧序列用于核对画面变化，不能证实用户端完整播放、实际听音、插件名称或最终成片表现。
