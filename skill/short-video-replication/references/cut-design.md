# 接镜设计：先决定为什么切，再准备两侧素材

本表综合电影剪辑资料形成制作建议，来源见 [研究依据](continuity-sources.md)。不是任何模型的“自动无缝”承诺。目标是动作、空间、情绪、信息和声音的连续感；单纯叠化不能修复这些关系。

## 按情况选接法

| 情况 | 建议接法 | 生成前要准备 | 动态验收/不适用条件 |
| --- | --- | --- | --- |
| 同一动作换机位：转身、递麦、拿商品 | 动作匹配直切，切在动作进行中 | 两机位覆盖同一个动作阶段，手和道具状态可匹配 | 方向、动作相位和速度连续；不可两镜各做一遍完整递麦 |
| 问答、倾听、反应 | 双人关系镜＋单人/过肩正反打 | 角色机位与轴线图、正确视线、听者闭口反应 | 不随意镜像翻转；左右/视线关系让观众明白谁对谁说 |
| 看/指招牌、客流或产品 | 视线匹配或有动机的对象切入 | 先有看/指的动作，再有准确目标和可识别空间 | 产品特写须回答当前问题或增加信息；不能无关插入 |
| 室外→室内、走廊→柜台 | 离开/入门动机＋目的地建立镜头或抵达动作；可省略途中路程 | 出入口方向、目的地标志、走入姿态、店内全景 | 不必拍完整步行，但必须可理解去哪里；不同空间不硬做穿墙插值 |
| 对白需要跨机位或场景 | J cut：下镜声先入；L cut：上镜声后出 | 可覆盖对白的倾听、反应、对象画面，独立声音源和切点 | 保留完整台词一次；不可借声桥掩盖错词、截词或口型错位 |
| 有明确视觉关联的跨场 | 构图/形状/运动匹配剪辑 | 主体位置、运动方向、画面重心和叙事关联 | 匹配外形不等于同一地点/同一商品；仍须交代时间空间跳跃 |
| 前景自然经过、出入门框 | 遮挡处隐切；动作或运镜带过 | 两侧自然遮挡及一致运动，切后揭示方向相容 | 必须真有覆盖画面，普通wipe特效不等于对象遮挡；不强塞路人挡镜 |
| 必须保持同一机位连续运动 | 当前接口支持时优先检验视频延长，或实际末帧续图生视频 | 已选实际视频/末帧、相容动作及光线 | 静帧缺运动历史；检查停顿、重复帧、速度突变、漂移。仅在用户允许可见切镜时才可改用换机位；禁切且未通过时保留未达标状态 |
| 两端状态相容且缺中间动作 | 当前接口支持时首尾帧桥接 | 真正可达的起止状态、运动路径与合理时长 | 全能参考不是首尾帧模式；不可把任意两场景形变当空间连续 |

转身和行走可在同镜内完成；不是每个动作词都要拆镜。常规对话优先清楚的直切和声桥，叠化适用于有意表达时间/状态变化，不能默认用于每处接缝。

## 分镜板内的接镜双格

每处相邻镜头用以下字段；若是明确场景跳跃，也记录其动机而非伪造连续动作。

| 字段 | 内容 |
| --- | --- |
| 接镜ID / 前后镜 | 稳定ID、双方物理镜号；与生成任务ID分开 |
| 为什么切 | 观众需要的新信息、动作延续或情绪反应 |
| 前镜出点格 | 实际图/候选/已生成帧的来源；手、头、道具、站位、运动阶段 |
| 后镜入点格 | 对应状态；机位、景别、视线、屏幕方向、空间锚点 |
| 接法与声音 | 动作切/视线切/场景省略等；音源ID、声切点和画切点 |
| 输出预算 | 目标剪点/帧号、过渡占用区间、双侧素材可选剪余量 |
| 缺素材与依赖 | 哪个角度、反应、环境声或实际末帧尚缺；是否需要新增任务 |
| 备用接法 | 当前动态不能匹配时，改哪个有叙事依据的机位或补什么动作 |
| 审核状态 | 计划/静板通过/真实接缝试剪/动态视听通过及问题 |

若镜头采用首尾帧，静板批准只是期望状态；上一镜生成后要取实际采用出点重新核对下一镜，不把历史候选当实际尾帧。动作匹配保留源素材重叠供选择，但成片不能重播动作。共享末/首帧续接时检查并裁去重复边界帧，不盲删所有片段首帧。

## 一对接缝的验收顺序

先用正常速度播放含两侧上下文和原声音的短试剪，判断是否自然；再逐帧定位手势、视线、道具、身份/衣着、亮度色温、速度与重复动作问题。单独听声音有无截词、回声、环境声突变；再看嘴形对应。静图、元数据和完整解码各有用处，但都不能单独证明丝滑。

优先改错的那一层：素材角度不对→补该机位；动作阶段不对→选可匹配源出入点或重做动作；声音重复→修音轨；空间关系错→补建立镜头/重设计；模型续接反复漂移→在授权范围内改为明确换机位。不要用更多特效、补帧或无关商品镜头遮掉结构问题。
