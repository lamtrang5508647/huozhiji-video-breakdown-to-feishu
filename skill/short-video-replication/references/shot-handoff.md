# 分镜与任务交接模板

用于拆解转制作、多角色对白或批量生成。按任务需要选用 Markdown、CSV 或 JSON；这些是交接字段，不是某个模型 API 的请求格式。记录放在当前项目中，未测量的时长、未提交的任务及未知费用保留“待测/未提交/未知”，不要填成实际值。

## 项目约束

记录参考素材身份与哈希、当前台词版本、角色和音色对应、目标画幅/时长、是否必须逐字、音频路线、指定平台/模型、可调整项、预算范围和本次完成阶段。沿用用户已有决定，只有影响执行且尚缺的信息才需补充。

## 每镜计划

| 字段 | 填写方式 |
| --- | --- |
| 制作镜号与目的 | 稳定镜号、销售/叙事作用；与源镜号分开 |
| 参考来源 | 源视频身份、源镜头/脚本段 ID、原片起止；新增镜头写“新增” |
| 保留与替换 | 原片观察、此次更换的人物/商品/场景、新增动作分开 |
| 素材绑定 | 实际文件或平台素材 ID，以及各自锁定的角色/服装/空间/音色 |
| 动态内容 | 景别/机位、动作顺序、运镜、开始和结束的连续性要求 |
| 画面板与剪切动机 | 实际动作格及其来源、角色站位与视线、该镜提供的信息、下一镜由什么动作或问题接上；同镜动作格不冒充多个切点 |
| 台词与话轮 | 原话、说话人、听者状态、台词 ID；跨镜同一句共用 ID |
| 声音路线 | 音画同生/原配音对嘴/原声画外音；参考音色与复用音频区分 |
| 计划时间 | 请求生成时长、计划输出起止；按模型限制和对白实测安排 |
| 生成提示词 | 实际提交的完整文本，引用名称与真实素材一一对应 |
| 验收点 | 本镜特有的嘴形、换人、递麦、手部、产品文字或转场检查 |

若用户要求保留原稿，另记每个原话轮 ID、原句、顺稿句、修改原因与是否重配；已认可音画分别标明复用身份和范围。保留原文段落与话轮顺序，不把改写稿标成原声。对排队、手持商品等需要画面支持的台词，记录画面是否真的出现对应关系；只见人群不等于已经看到排队。

一段原片可能生成多个素材；一个生成素材也可能剪成多个镜头。允许这种映射，但不要因此重写原片区间。使用本仓库对齐表时，保留它的源哈希与段/镜号，另外测量对白；不将时间交集平均分给文字。

## 生成回执

每次尝试独立记录镜号、服务/模型、任务 ID、提交时刻、引用素材、参数、提示词版本、状态、返回素材身份、实际时长和计费。重试沿用同一制作镜号并增加尝试记录，不覆盖旧任务。尚未取回或未播放的结果不能标为已验收。

## 合成清单

每个视频或音频片段明确三部分：素材身份及其源起止、目标轨道及输出起止、变速/裁切/转场处理。参考原片区间仅用于溯源，不自动成为素材裁切参数。

例如一段对白跨两个画面时，画面各有输出区间，完整对白在音轨只放置一次；两个制作镜号引用同一台词 ID。若拆成两段音频，记录各自音频源区间并检查接缝。没有实际口播时间证据时，不凭字幕字符数制造精确对齐。

导出后补记真实文件身份、实际时长/画幅、字幕及水印处理、完整解码结果、实际视听审阅范围和遗留项。计划、任务回执、剪辑安排和成片事实分别保留，便于判断下一步是生成、重剪还是审阅。
